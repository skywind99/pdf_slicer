# 📄 Auto PDF Slicer — 스캔 답안지 자동 분할기

## 파일 구성

```
pdf_slicer/
├── pdf_slicer.py      ← 메인 프로그램 (파이썬 직접 실행)
├── 빌드_EXE.bat       ← 단독 EXE 빌드 스크립트 (더블클릭)
└── README.md
```

---

## 방법 A — 파이썬 직접 실행 (개발/테스트)

```bash
pip install customtkinter PyMuPDF Pillow
python pdf_slicer.py
```

---

## 방법 B — EXE 배포판 만들기 (추천)

1. `빌드_EXE.bat` 더블클릭
2. 자동으로 패키지 설치 + 빌드 진행 (1~3분)
3. `dist/PDF_Slicer.exe` 완성 → 이 파일만 배포

> 💡 EXE는 파이썬 없는 PC에서도 바로 실행됩니다.

---

## 사용법

| 항목 | 설명 |
|---|---|
| ① 원본 PDF | 스캔된 전체 답안지 PDF 선택 |
| ② 저장 폴더 | 파일 선택 시 자동으로 `분할완료/` 폴더 지정 |
| ③ 파일명 설정 | 학년반 앞자리 + 접미어(선택) 입력 |
| ④ 페이지 수 | 학생 1명 답안 페이지 수 (예: 앞뒤 2장이면 `2`) |

### 결과 파일명 예시

- 학년반 `109`, 접미어 `_수학` → `10901_수학.pdf`, `10902_수학.pdf`, …
- 학년반 `109`, 접미어 없음  → `10901.pdf`, `10902.pdf`, …

### 미리보기 조작

- 마우스 휠 ↑↓ 로 페이지 넘기기
- ◀ ▶ 버튼으로 페이지 이동
